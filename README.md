# Remotik Charge

Заряд беспроводной мыши, гарнитуры и клавиатуры Razer — прямо на панели задач Windows, рядом с часами.
Razer Synapse не нужен.

**[Скачать последнюю версию →](https://github.com/ruslaller/remotik-charge-releases/releases/latest/download/RemotikCharge-win-Setup.exe)**

---

## Русский

**Установка.** Запустите `RemotikCharge-win-Setup.exe`. Права администратора не нужны, программа ставится только
для вас и сама запускается вместе с Windows. Дальше она обновляется сама.

**Windows покажет «Windows защитила ваш компьютер»** — у программы пока нет платной цифровой подписи.
Нажмите **«Подробнее» → «Выполнить в любом случае»**. Если ругается антивирус — это ложное срабатывание
на неподписанный файл.

**Что умеет**
- Заряд и зарядка на панели задач — на всех мониторах или на выбранных. На мониторе с игрой на весь экран виджет прячется.
- `Ctrl+Shift+B` в игре — показать заряд поверх игры (игра в режиме «в окне без рамки»).
- Уведомление, когда пора заряжать. Выключенное устройство исчезает с панели и возвращается, когда его включат.
- Правый клик по виджету или по значку батареи в трее — все настройки.

**Устройства.** Мыши и клавиатуры Razer на донгле и кабеле (подхватываются сами), гарнитура
Razer BlackShark V2 Pro. Устройство не появилось — напишите автору.

**Удаление.** Параметры Windows → Приложения → Установленные приложения → Remotik Charge → Удалить.

## Українська

**Встановлення.** Запустіть `RemotikCharge-win-Setup.exe`. Права адміністратора не потрібні, програма ставиться
лише для вас і сама запускається разом з Windows. Далі вона оновлюється сама.

**Windows покаже «Windows захистила ваш комп'ютер»** — у програми поки немає платного цифрового підпису.
Натисніть **«Докладніше» → «Однаково запустити»**.

**Що вміє:** заряд і заряджання на панелі завдань (усі монітори або вибрані), `Ctrl+Shift+B` у грі — показати
заряд поверх гри, сповіщення про низький заряд, усі налаштування — правим кліком по віджету.

**Видалення.** Параметри → Програми → Інстальовані програми → Remotik Charge → Видалити.

## English

**Install.** Run `RemotikCharge-win-Setup.exe`. No admin rights needed; it installs for you only, starts with
Windows and keeps itself up to date.

**Windows SmartScreen will say "Windows protected your PC"** — the app is not code-signed yet.
Click **More info → Run anyway**.

**What it does:** battery and charging on the taskbar (all or chosen monitors), `Ctrl+Shift+B` in a game shows
the levels over it, a low-battery notification, all settings on right-click.

**Uninstall.** Settings → Apps → Installed apps → Remotik Charge → Uninstall.
